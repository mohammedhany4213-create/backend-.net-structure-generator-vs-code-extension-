# Changelog

All notable changes to the Backend Structure Generator extension are documented here.

## [0.0.1] - 2026-09-07

### Added

- Guided .NET backend project generation from VS Code.
- .NET 8, 9, and 10 target selection.
- Simple / Folder-Based architecture.
- Clean Architecture.
- N-Layered Architecture.
- Vertical Slice Architecture.
- ASP.NET Core Web API support.
- Controllers and Minimal API styles.
- Worker Service support.
- Console Application support.
- Automatic solution/project creation and project references.
- Automatic restore and build validation.
- Generated README for created projects.
- `Ctrl+Alt+B` keyboard shortcut.
